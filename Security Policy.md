# Security Policy

## Supported Versions

Currently, only the latest major version of HookMock receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within HookMock, please send an e-mail to the maintainers directly rather than creating a public issue. We will reply within 48 hours to acknowledge the report and provide an expected timeline for a patch.

Because HookMock is designed purely for **local development and testing**, standard production attack vectors are heavily mitigated. However, any issues related to unsafe execution of local payloads or dependency vulnerabilities will be treated with high priority.
